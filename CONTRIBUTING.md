# Contributing to Word Territory

Contributions are welcome.

Useful contribution areas:

- better dictionary curation
- stronger but faster bot logic
- mobile UI improvements
- replay mode
- online play
- accessibility
- visual effects for capture / lock / combo moments
- balance testing

Please keep the core identity intact:

> Word Territory is a spatial strategy game using words, not a pure vocabulary contest.

Core strategic values:

- Territory Swing
- Capture
- LOCK
- Shape
- Threat
- Expansion

Please preserve attribution:

